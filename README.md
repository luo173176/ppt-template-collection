## 使用方法

1. **先装字体。** Windows：选中 `fonts/` 下的 `.ttf` / `.otf` 右键“安装”；macOS：双击导入 Font Book。缺字体会导致版式回退。
2. **打开模板。** `simon-awen/` 与 `slidescarnival/` 下的 `.pptx` 可直接使用。
3. **下载大模板。** 超过 100 MB 的 23 个文件在 [Release v1.0](https://github.com/luo173176/ppt-template-collection/releases/tag/v1.0)，完整清单见 [LARGE_FILES.md](LARGE_FILES.md)。

一次拉取全部 Release 附件：

```bash
gh release download v1.0 -R luo173176/ppt-template-collection -D release
```
